# THIRTY FOUR brand spec

## Identity assets

- Existing logo: `components/Logo.tsx` (preserved in the site header and footer).
- User-provided Hero image: `public/editorial/thirty-four-hero.png`.

## Visual system

- Body type: Manrope (`--font-manrope`).
- Display type: Cormorant (`--font-cormorant`).
- Base palette: monochrome black, white, and neutral grays used by the existing editorial storefront.
- Local accent: warm gold `#E3B15B` for Footer headings only; do not apply globally.
- Hero treatment: full-color user-provided product image with a restrained dark veil for text contrast.

## Preservation notes

- Keep the existing Header, navigation, and store routes intact.
- Keep the current Body shopping flow; remove only the redundant `HouseGallery` section.
- Do not recolor headings outside the Footer.
